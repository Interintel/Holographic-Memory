Fun with holographic memory. Use the dynamic_holographic_shape_gui.py program to create and label shapes (shapes=Circle, Square, Triangle, Rectangle) 
and then draw a shape and ask for the recall. 

This app uses Holographic Reduced Representation to store and read.

What it does:

Opens a drawing window.

You draw a shape with your cursor.

Type a label like square, circle, triangle, etc.

Click Save Shape + Label.

It stores the shape and label in: dynamic_holographic_shape_memory.npz

Simple to use and to run
